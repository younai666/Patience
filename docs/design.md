# 设计依据

唯一 UI/UX 来源：[Caho1/open-claude-ui](https://github.com/Caho1/open-claude-ui/tree/c1f923ae0051a871941b98a0e2e3183a545e6a85)，基线 `c1f923ae0051a871941b98a0e2e3183a545e6a85`。该库提供 React/CSS，没有 Android 组件。Patience 使用 Compose Foundation 原生移植所需子集，没有使用 Material 或其他设计体系。

| 应用实现 | 上游依据 |
| --- | --- |
| 主页正文 | `ChatMessageBubbles.tsx` 的透明正文画布；主页只保留当前会话编辑，空白内容没有占位文案 |
| 二级会话目录 | 用户要求的每会话一行横长胶囊；采用 `SegmentedControl.tsx` 的 `999px` 胶囊半径与 CDS 9% 次级填充，复用 `CdsButton` 的 48dp 触控区域；只显示单行标题、编辑和删除，不放预览与时间 |
| 页面版心、正文 | `--chat-max-width` 768；`--chat-gutter` 32；移动输入至少 16；prose 行高 24；系统 sans 字体回退 |
| 图标/按钮 | `CdsButton.tsx` 外层触控、内层绘景结构；32/40 高、8/12 圆角；图标 20，256 坐标系、16 常规线宽 |
| 标题栏 | 标准库 `--df-titlebar` 的 48 高；横屏时保留编辑空间 |
| 触控区域 | v2 第 2.8 节命中区域补偿：保留绘景尺寸，将 Android 点击目标扩大至 48dp |
| 按钮反馈 | `cds-theme.css` 的 `.975` 按压，60ms；450ms 松手，完整 15 点 `--cds-btn-spring`；hover 150ms `(.16,1,.3,1)` |
| 删除确认 | `ConfirmationDialog.tsx` 的 400 最大宽、16 圆角、24 内边距；`.95 → 1` / 200ms `(.165,.84,.44,1)`；返回/遮罩关闭，原生 Dialog 焦点约束 |
| 交互与层级 | `cds-theme.css` 暗色 Token：5% hover；9% 次级按钮填充与边界；无套娃边框 |

用户明确要求的黑白审美优先：画布和弹窗固定纯黑 `#000000`，所有文字固定纯白 `#FFFFFF`，不跟随系统切换浅色。强调按钮使用上游次级填充，避免反色按钮产生黑字。用户新指定的小图标使用手绘配色，垃圾桶为红色；这不改变画布与文字色。此项覆盖上游默认底色、次级文字色和陶土强调色，不宣称这些黑白值是上游默认值。其他几何、交互与动效取自上游实现；源码与文档有差异时以当前源码为准。Compose 动画随 Android 系统动画比例缩减/关闭。

编辑器保留 Android 原生输入法合成、选区、复制粘贴、撤销和换行行为，不拦截 Enter 或实现发送动作。WebKit 专属守卫不移植到原生输入管道。媒体、语音、模型选择、沙箱、网络重试等上游模块不属于本产品功能。

Launcher 图标使用 `anthropic-art` 和内置图像生成工具原创，采用 oat `#E3DACC` 满幅背景、ivory `#FAF9F5` 不规则纸片、`#141413` 手绘墨线。生成提示词保存在 `icon-prompt.txt`。图标与黑白应用界面分别遵循用户指定的两项要求。

三个 UI 图标同样使用 `anthropic-art` 与内置图像生成工具原创：会话目录为叠放纸页、编辑为铅笔，均为 oat 背景与黑墨线；垃圾桶使用 coral `#EBCECE` 背景与用户明确要求的红色笔触。原图与完整提示词保存在 `ui-icons/`，Android 使用相同图像缩小至 128px 的资源，在 32dp 绘景区显示，点击区域仍为 48dp。
